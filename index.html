Incident triage

Live

The first 15 minutes

The same checklist works for every incident. Ticks are saved in this browser only, so you can keep your place during a long call.

  • Acknowledge the page so nobody else picks it up and the escalation timer stops.
  • Confirm it's real: run error rate or latency by feature for the last hour and compare it with the same hour yesterday.
  • Scope it: which feature experience, which region, which client version, which Foundry deployment?
  • Check outside causes: Azure status, Foundry resource health, and any recent deploy or flag change.
  • Pick a severity using the severity matrix. If you're unsure, choose the higher one; it's cheap to downgrade.
  • Declare and open a channel (Sev 1–2). Name an Incident Commander, even if that's you for now.
  • Post a first update using the comms template, even if all it says is "investigating".
  • Mitigate before you debug: roll back, fail over, or shed load if any of those clearly helps.
  • Start the timeline: write down what you saw and did, with timestamps.
For senior managers · joining a live incident

Your role

  • Make sure an Incident Commander exists.
  • Make business decisions quickly: cost, customer comms, priorities.
  • Shield the team from executive interruptions.

Questions to ask

  • Who is the Incident Commander?
  • What's the customer impact right now, in numbers?
  • What's the current mitigation, and when is the next update?
  • What do you need from me?

Avoid

  • Asking for root cause mid-incident.
  • Directing engineers on the call.
  • Messaging responders directly.

How this guide thinks

Users first

Severity follows user impact, not which alert fired or how loud it was.

Mitigate, then debug

Stop the bleeding with a rollback, failover, or load shed. Find the root cause after users are unblocked.

Query first

Dashboards are rare here, so every step comes with a query you can run in Application Insights.

Blameless

Gaps in tooling and ownership belong to the system, not to people. Write them down and fix them.

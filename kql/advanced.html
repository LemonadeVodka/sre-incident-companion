Module 3: Across Layers

For SRE engineers and ambitious NOC members. Write reusable queries, connect a request to everything it called, query the edge and gateway logs in Log Analytics, and use the patterns behind our burn-rate and anomaly queries.

  • let names a value once at the top. That's our parameter block convention.
  • join on operation_Id connects a request to its dependencies. union stacks several tables.
  • Edge and gateway logs live in Log Analytics (AzureDiagnostics, ApiManagementGatewayLogs). Use column_ifexists when column names vary.
  • make-series + series_decompose_anomalies finds unusual spikes automatically.

Lesson 9: Parameters With let

Concept. let name = value; defines a value once. We put every environment-specific value at the top in a parameter block, tagged [NIMBUS] (must change), [TUNE] (adjust), or [AZURE] (real schema), so anyone can reuse the query safely.

KQLOur Parameter-Block ConventionChange the top, leave the body alone
// ── Parameters ─────────────────────────────
let role = "writing-assist-svc";   // [NIMBUS] cloud_RoleName of the service
let window = 1h;                   // [TUNE] how far back to look
// ── Query ──────────────────────────────────
requests
| where timestamp > ago(window) and cloud_RoleName == role
| summarize p50 = percentile(duration, 50), p95 = percentile(duration, 95) by bin(timestamp, 5m)
| render timechart

Lesson 10: Joining Requests and Dependencies

Concept. Every request has an operation_Id (the trace ID), and its dependency calls share it. join lines them up, so you can see how much of a request's time went to each layer. union stacks tables, which is useful for walking one trace end to end.

KQL · LessonHow Much of Each Request Is the Model?Join on operation_Id
requests
| where timestamp > ago(1h) and cloud_RoleName == "writing-assist-svc"
| project operation_Id, request_ms = duration
| join kind=leftouter (
    dependencies
    | where timestamp > ago(1h) and target has "openai.azure.com"
    | summarize model_ms = sum(duration) by operation_Id
  ) on operation_Id
| summarize p95_request = percentile(request_ms, 95), p95_model = percentile(model_ms, 95)
KQL · LessonWalk One TraceEverything that happened for one request, in order
union requests, dependencies, exceptions, traces
| where timestamp > ago(1d) and operation_Id == "PASTE_OPERATION_ID"
| project timestamp, itemType, cloud_RoleName, name, target, duration, resultCode
| order by timestamp asc

Lesson 11: Edge and Gateway Logs

Concept. Our CDN (Front Door) and gateway (APIM) write to Log Analytics, not Application Insights. Front Door logs sit in AzureDiagnostics with a Category. Column names vary by setup, so column_ifexists("name", "") keeps a query from breaking when a column is missing.

KQL · LessonEdge Status Codes Over TimeLog Analytics workspace
AzureDiagnostics
| where TimeGenerated > ago(6h) and Category == "FrontDoorAccessLog"
| extend status = toint(column_ifexists("httpStatusCode_s", ""))
| summarize ok = countif(status < 400), c4xx = countif(status between (400 .. 499)), c5xx = countif(status >= 500)
    by bin(TimeGenerated, 5m)
| render timechart
KQL · Lesson401s at the Gateway by APILog Analytics workspace
ApiManagementGatewayLogs
| where TimeGenerated > ago(6h)
| summarize total = count(), unauthorized = countif(ResponseCode == 401) by ApiId
| extend pct_401 = round(100.0 * unauthorized / total, 2)
| order by pct_401 desc

Log tables like these are not sampled, so count() is correct here. To compare all layers side by side, see the errors-by-layer query.

Lesson 12: Patterns

Concept. A few reusable patterns turn raw numbers into answers. Anomaly detection flags unusual points against a learned pattern. Top movers shows what changed most. Burn rate says whether we're using up the error budget fast enough to page someone.

KQL · LessonAnomalies in Failuresmake-series + series_decompose_anomalies
requests
| where timestamp > ago(7d)
| make-series failures = sumif(itemCount, success == false) default = 0 on timestamp step 15m
| extend (anomaly, score, baseline) = series_decompose_anomalies(failures, 2.5)
| mv-expand timestamp to typeof(datetime), failures to typeof(long), anomaly to typeof(int)
| where anomaly != 0

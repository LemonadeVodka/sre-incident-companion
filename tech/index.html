Technical Corner

You don't need to be the best engineer in the room. You need enough depth to ask the question that unlocks the investigation, to spot a weak explanation, and to hold your own with a deeply technical director. This course gets you there for cloud-side AI infrastructure.

  • Goal: manager depth. You can explain each layer, recognize how it fails, read the chart, and ask the next question.
  • Each module covers: what it is → how it fails → what the charts look like → questions to ask → go deeper.
  • Allow about 30–45 minutes per module. Do one a week with your Ops lead.

Learning Path

  1. FoundationsKnow the Layers and the Latency & Errors Primer. The mental model everything else builds on.
  2. AI Serving & CapacityHow models are served: tokens, first-token latency, quota, 429s, PTU vs pay-as-you-go, model lifecycle, cost.
  3. RAG, Agents & Model ChangesRetrieval, tool calls, and evals. Why AI systems regress with no code change.
  4. Network & IdentityEdge, gateway, DNS, TLS, tokens. Where 401s, 403s, and 5xx at the edge come from.
  5. Observability for AITraces, GenAI telemetry, sampling, and the dashboards to demand.
  6. TroubleshootingThe layer-by-layer walkthrough, then system-level deep dives.
  7. Failure CatalogFifteen real-shaped failures, each with its signature and first questions. Use it as flashcards.
  8. KQLKQL Training, so you can check a claim yourself in two minutes.

The Method

Every module follows the same troubleshooting habit, which is also how you coach others:

1. Where?

Which layer returned the error or added the time? Use one trace, not a theory.

2. Since When?

Compare with the same hour last week. Find the change point.

3. What Changed?

Deploys, config, model versions, prompts, quota, partners, traffic.

4. Who Exactly?

Region, client version, feature, partner, tenant. A narrow cohort is a clue.

5. What Would Prove It Wrong?

Ask for the disconfirming check before acting on a single hypothesis.

Use This with Your Director

A highly technical director respects precise questions far more than broad reassurance. "Did the P95 rise in prefill or decode?" earns more trust than "the team is on it". See Managing Up.

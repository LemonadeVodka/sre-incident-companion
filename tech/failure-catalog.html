Technical Corner · Module 7

Failure Catalog

Fifteen failures that happen in real hybrid AI products. Learn their signatures and you'll recognize most incidents within the first ten minutes, and know which question to ask first. Use them as flashcards with your Ops lead, or as tabletop scenarios.

  • Each entry: signature (what you see), layer, and first questions.
  • Many failures look alike at first. The first questions are designed to tell them apart.

Model and Capacity

1. Quota Exhaustion

Signature: 429s from the model at peak hours, P95 up if retries hide them.

Layer: Model provider.

Ask: "What share of TPM are we using at peak, per deployment? Who's the biggest consumer?"

2. Noisy Neighbor

Signature: A customer-facing feature throttles when a background job or another team's feature bursts.

Layer: Model provider (shared deployment).

Ask: "Which features share this deployment? Did anyone start a batch job?" (deep dive)

3. Device-to-Cloud Fallback Surge

Signature: Cloud requests jump with no change in active users. Often follows a client, driver, or on-device model update.

Layer: Device orchestrator → cloud.

Ask: "What's the local vs cloud split by client version? What shipped to devices?" (deep dive)

4. Silent Model Version Change

Signature: Latency, output length, or content-filter rate shifts at a single point in time, with no deploy.

Layer: Model provider.

Ask: "Did the model version change? Is the deployment on auto-upgrade?"

5. Regional Capacity Shortage

Signature: Higher TTFT and 429s in one region, while other regions are fine. Provider status may show degradation.

Layer: Model provider.

Ask: "Can we shift to the secondary region, and does it have quota?"

6. Prompt or Context Bloat

Signature: Input tokens per request rise gradually or in a step. TTFT and cost rise together.

Layer: Orchestrator / retrieval.

Ask: "What changed in the prompt template or retrieval settings? Show input tokens per feature over 30 days."

Network and Identity

7. Edge Timeouts on Long Answers

Signature: 504s at the edge on non-streaming, long-running requests. The origin finishes, but too late.

Layer: Edge / CDN.

Ask: "Are these generated at the edge? What's the origin response time compared with the edge timeout?"

8. WAF False Positives

Signature: 403s for some prompts after a WAF rule update. Longer or code-like prompts are hit most.

Layer: Edge / WAF.

Ask: "Which rule is matching? When was the rule set changed?"

9. Client Token Refresh Bug

Signature: 401s for one client version, often about an hour after sign-in.

Layer: Device client / identity.

Ask: "Is it one client version? Does the timing match the token lifetime?" (401 investigation)

10. Key or Secret Rotation

Signature: 401s or 403s for all users of a service, starting at a precise minute.

Layer: Identity / gateway / service-to-service.

Ask: "Was any key, secret, certificate, or role assignment changed at that time?"

11. Private DNS Misconfiguration

Signature: Total failure of every call to one dependency, right after a network change.

Layer: Networking.

Ask: "What does the name resolve to from inside the service network?"

System Behavior

12. Retry Storm

Signature: A short blip becomes a long outage. Request volume to the dependency multiplies while it's struggling.

Layer: Orchestrator / clients.

Ask: "What are our retry counts and backoff? Is volume to the dependency higher than user traffic explains?" (deep dive)

13. Connection Pool Exhaustion

Signature: Timeouts in the orchestrator on some instances, while downstream reports healthy.

Layer: Orchestrator (Rust services).

Ask: "Is it some instances or all? What do pool usage and wait time show?" (Rust failure modes)

14. Partner or Integration Platform Outage

Signature: Errors only in features using one partner. Agent answers slow down while tool calls wait.

Layer: Integration platform / partner.

Ask: "Is it one connector or all? Is the circuit breaker open? What's on their status page?" (partners in incidents)

15. Sync Relay Degradation

Signature: Catch Up and Next Step late on the second device. No errors on the first device.

Layer: Sync relay.

Ask: "What's relay success and sync lag by region? Is it cross-network sync only?" (sync relay)

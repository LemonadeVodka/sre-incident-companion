# SRE Incident Companion

A lightweight companion for running incidents from detection through postmortem.

Live site: https://lemonadevodka.github.io/sre-incident-companion/

## Purpose

- Give responders one place to find the current incident state, roles, and next steps.
- Keep incident communication consistent across the response team and stakeholders.
- Capture the timeline and follow-ups while the incident is still fresh.
